📊 Pre-built Visualization Queries

Copy these queries into the InfluxDB Data Explorer (Explore tab):

1. View All Channels (Last 30 seconds)

from(bucket: "eeg_data") |> range(start: -30s) |> filter(fn: (r) => r["_measurement"] == "eeg_raw") |> filter(fn: (r) => r["_field"] == "mean") |> group(columns: ["channel"])

2. Compare Raw vs Preprocessed (FP1 Channel)

raw = from(bucket: "eeg_data") |> range(start: -1m) |> filter(fn: (r) => r["_measurement"] == "eeg_raw") |> filter(fn: (r) => r["channel"] == "FP1") |> filter(fn: (r) => r["_field"] == "mean") |> map(fn: (r) => ({r with stream: "raw"})) preprocessed = from(bucket: "eeg_data") |> range(start: -1m) |> filter(fn: (r) => r["_measurement"] == "eeg_preprocessed") |> filter(fn: (r) => r["channel"] == "FP1") |> filter(fn: (r) => r["_field"] == "mean") |> map(fn: (r) => ({r with stream: "preprocessed"})) union(tables: [raw, preprocessed])

3. Signal Quality Monitor (All Channels)

from(bucket: "eeg_data") |> range(start: -2m) |> filter(fn: (r) => r["_measurement"] == "eeg_raw") |> filter(fn: (r) => r["_field"] == "quality") |> group(columns: ["channel"])

4. Amplitude Range (Min/Max)

from(bucket: "eeg_data") |> range(start: -1m) |> filter(fn: (r) => r["_measurement"] == "eeg_raw") |> filter(fn: (r) => r["_field"] == "min" or r["_field"] == "max") |> filter(fn: (r) => r["channel"] == "FP1") |> pivot(rowKey: ["_time"], columnKey: ["_field"], valueColumn: "_value")

📈 Data Schema

Measurements

  • eeg_raw - Raw EEG data
  • eeg_preprocessed - Filtered data
  • eeg_raw_metadata - Configuration
  • eeg_preprocessed_metadata - Config

Fields

  • mean - Average amplitude
  • min - Minimum value
  • max - Maximum value
  • quality - Signal quality (0-1)
  • sample_count - Samples per message

Tags

  • channel - FP1, FP2, F3, F4
  • session_id - Session identifier
  • frame_id - Frame reference

🎯 Creating Your First Dashboard

  1. Go to InfluxDB UI
  2. Click Dashboards in the left sidebar
  3. Click + Create Dashboard
  4. Add a new cell, paste one of the queries above
  5. Choose visualization type:
    • Line Graph - Best for time series
    • Band Plot - For min/max range
    • Gauge - For signal quality
  6. Set auto-refresh to 5s or 10s
  7. Save your dashboard!

💡 Tips & Tricks

  • Auto-refresh: Set refresh interval in dashboard settings for real-time view
  • Time ranges: Use -30s, -1m, -5m for recent data
  • Multiple channels: Remove channel filter to see all 4 channels overlaid
  • Comparison view: Create 2 cells side-by-side for raw vs preprocessed
  • Export data: Use the Download CSV option from query results
